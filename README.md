# SoundWave for Android — прототип 0.1

Нативный интерфейс Android + Python (Chaquopy + yt-dlp). Никакого сервера и никаких токенов.

## Что работает по проектному коду

- Вставка ссылки из буфера обмена и обычная клавиатура Android
- Ссылки вида `https://soundcloud.com/...` и `https://on.soundcloud.com/...`
- Поиск отдельного трека (название / исполнитель / обложка)
- Загрузка доступного аудио, отображение прогресса
- Системное окно «Сохранить как» (папку выбираешь сам)
- Нативный тёмный интерфейс; можно поделиться ссылкой из приложения SoundCloud

**Внимание:** это исходный Android-проект, не готовый APK. Автоматические тесты Python проходят, но Android-приложение ещё не собиралось и не запускалось на реальном телефоне. Веб-сервис SoundCloud может менять защиту и форматы, поэтому отдельные треки могут не загружаться. Пользуйся только для сохранения музыки, на которую есть разрешение.

## Самый простой способ собрать APK без мощного ПК (GitHub Actions)

1. Войди на github.com, создай новый **публичный** репозиторий (в проекте нет ключей и паролей).
2. Залей **содержимое** этой папки, сохранив структуру `.github/workflows/build-apk.yml`, `app/...` и остальные файлы. Удобнее через GitHub Desktop или `git`.
3. Открой вкладку **Actions** -> **Build SoundWave APK** -> **Run workflow**. При загрузке в `main` сборка также запускается автоматически.
4. В успешной сборке в разделе **Artifacts** скачай `SoundWave-Android-APK.zip`.
5. Распакуй его: внутри `app-debug.apk`. Отправь этот APK на телефон и установи, если доверяешь собственному собранному приложению. Android может попросить разрешение на установку из выбранного приложения.

Сборка через GitHub использует его сервер, но **само приложение после сборки работает локально на телефоне**, без нашего хостинга. Доступность и квоты бесплатных GitHub Actions зависят от условий GitHub.

## Сборка через Android Studio

1. Поставь Android Studio и открой эту папку как проект (`File -> Open`).
2. Выбери JDK 17, если Android Studio не выбрала автоматически.
3. Дождись загрузки Gradle и SDK Android 35.
4. Выбери меню `Build -> Build Bundle(s) / APK(s) -> Build APK(s)`.
5. Полученный файл будет в `app/build/outputs/apk/debug/app-debug.apk`.

Для сборки нужен интернет: Gradle скачает инструменты и Python-зависимость. **На телефоне Python не нужен**.

## Поддержка телефонов

- Android 8.0+ (API 26), архитектура ARM64 (современные Android-телефоны).
- APK предназначен для тестирования, подписан отладочным ключом при сборке.
- Если решишь распространять обновления широко, позже создадим постоянный release-ключ подписи.

## Ограничения первой версии

- Только отдельные SoundCloud-треки, не плейлисты.
- Длительные загрузки должны выполняться при открытом приложении; фонового сервиса пока нет.
- Скачивание выполняет `yt-dlp`. Если автор не разрешает тебе сохранять трек, не скачивай его.
- MP3-конвертация не включена, сохраняется доступный аудиоформат (.mp3/.m4a/.webm и др.).
- Плеер и история скачиваний — возможные следующие версии.
